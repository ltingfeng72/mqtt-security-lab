# ProtoFuzz-AI

## 项目简介

ProtoFuzz-AI 是一个用于学习和研究 MQTT 5.0 协议及相关软件开发流程的本地项目。

## 本地实验用途

本项目当前用于搭建受控的本地实验环境，整理项目规范，并为后续的协议学习、程序开发和示例验证提供基础。

## 基本环境要求

后续开发预计使用以下基础环境：

- 支持 Docker 的本地开发系统
- MQTT 5.0 兼容的软件环境
- Python 3
- 常用的 Git 与代码编辑工具

具体版本和安装步骤将在相关功能加入后补充。

## 当前已有文件

- `README.md`：项目简介与基础本地开发环境说明。
- `AGENTS.md`：项目范围、开发约定和执行边界说明。
- `SECURITY_SCOPE.md`：本地实验环境的使用范围说明。

项目后续将逐步添加：

相关内容将在实现后同步补充使用说明。
